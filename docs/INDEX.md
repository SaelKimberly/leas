# leas documentation

Wiki hub. Every folder carries its own `INDEX.md`.

| Folder | What it holds |
| --- | --- |
| `architecture/` | How the system is put together: crate graph, runtime boundaries, durable design decisions |
| `guides/` | Task-oriented instructions: using the TUI, building, releasing |
| `reference/` | Specifications to look facts up in: schema, ordering law, protocols, crypto posture |
| `history/` | Superseded designs and the pre-Aegis lineage, kept as brief notes |
| `research/` | Ad-hoc studies and the evidence behind decisions. Not authoritative |
| `aegis/` | Aegis workspace (specs, plans, ADRs, baselines). Frozen, not part of this wiki |

Start here: [`architecture/architecture.md`](architecture/architecture.md). For the screen-by-screen manual, go to [`guides/tui-manual.md`](guides/tui-manual.md).
