# leas documentation

Wiki hub. Every folder carries its own `INDEX.md`.

| Folder | What it holds |
| --- | --- |
| `architecture/` | How the system is put together — crate graph, runtime boundaries, durable design decisions |
| `guides/` | Task-oriented instructions — using the TUI, releasing/publishing |
| `reference/` | Factual specifications to look things up in — DB schema, ordering law, protocols, crypto posture |
| `history/` | Superseded designs and the pre-Aegis lineage, kept as brief notes |
| `research/` | Ad-hoc studies and evidence that informed decisions |
| `aegis/` | Aegis workspace (specs, plans, ADRs, baselines) — **frozen**, not part of this wiki |

Start here: [`architecture/architecture.md`](architecture/architecture.md).
