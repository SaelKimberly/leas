# Durable design decisions

The rules a change must not break, one numbered entry each, with the code or ADR that enforces it. This page states the decision and links to its owner: design detail, tables and measurements live in `reference/`. The crate map is in [`architecture.md`](architecture.md); the ADR bodies are in [`../aegis/INDEX.md`](../aegis/INDEX.md).

## Identity and schema

1. **Typed schema, one file.** SQLite through `toasty` 0.11 on Turso `=0.9.0-pre.2`, reached through the crate's own local-only driver fork (`crates/leas-db/src/driver/`). 11 typed tables: `endpoints`, `endpoint_ip`, `protocols`, `profile_stats`, `endpoint_groups`, `groups`, `routing_rules`, `dns_settings`, `route_probes`, `endpoint_rank`, `app_meta`. Tables and flows: [`reference/database.md`](../reference/database.md).
2. **The schema cursor is a migration cursor, not a wipe tag.** `PRAGMA user_version` (now 19) is read by `crates/leas-db/src/schema/mod.rs`: a current file is a no-op, a fresh file applies the seed, a supported older version migrates, only an unknown cursor wipes. Never bump `SCHEMA_VERSION` to force a change; raw DDL lives in `schema/ddl.rs`. ADR 0012.
3. **Profile identity is a frozen binary wire format.** `uid = sig ^ cred_hash`, written by the per-kind writer in `crates/leas-proto/src/proto_spec/identity.rs` over non-default, explicitly set fields only. Endpoints never participate; credentials are domain-separated, so `cred_hash = 0` and `uid == sig` when there are none. Every field is tag+length framed and the write order is frozen: changing what identity covers re-keys stored rows, see the checklist in [`reference/database.md`](../reference/database.md).

## Backends

4. **Three runtime backends, two persisted.** `CoreManager` (`crates/leas-core/src/process.rs`) runs the xray-core and sing-box subprocesses; `leas-native` is the third and runs in-process, with no binary, config file or gRPC. The proto enum stays `{Xray, SingBox}`: the native choice is runtime-only, recomputed per connect by `resolve_runtime_core` (`crates/leas/src/ops/connect.rs`) and never written to the DB. ADR 0004.
5. **Protocol-kind auto-resolution picks the subprocess core.** `core_mapping::resolve_core` (`crates/leas-proto/src/proto_spec/core_mapping.rs`): TUIC, Hysteria v1, Naïve, AnyTLS, ShadowTLS, Tor, SSH, Tailscale, ShadowsocksR, Redirect, TProxy and Mixed go to sing-box, everything else to xray-core. Shadowsocks is cipher-aware (legacy ciphers go to sing-box), and a forced override always wins.
6. **One core at a time,** the in-process server included. Only one backend runs per session. Teardown windows: `PREV_SESSION_TEARDOWN` (5 s) before a new session binds, `DISCONNECT_TEARDOWN` (3 s) before the task is aborted (`crates/leas/src/ops/connect.rs`).
7. **The native capability gate fails closed.** `capability::support_reason` (`crates/leas-native/src/capability.rs`) decides whether native may serve a row; a refusal is a result, persisted as an `UNTESTABLE_PREFIX` marker (`crates/leas/src/ops/ping.rs`), never a silent downgrade.
8. **The local inbound is one mixed listener.** The native session binds a single SOCKS5 + HTTP CONNECT port (`crates/leas-native/src/inbound/mixed.rs`, first byte selects the protocol). Subprocess builders keep the same model: a configured `mixed_port` supersedes `socks_port`/`http_port`, the SOCKS-facing port is `mixed_port ?? socks_port` (`BuildParams::local_port`; an HTTP-only listener never speaks SOCKS5), and rule selectors `socks-in`/`http-in` are remapped to `mixed-in` by `config_builder::effective_inbound_tags`.

## Ordering and the Profiles page

9. **One ordering law, materialized.** The link key is `(bin, stab, u64::MAX - weight, -last_seen_at, protocol_id)`, implemented once in `RankLink::key` (`crates/leas-db/src/endpoint_rank.rs`). The page order is `(band, rank_bin, rank_stab, rank_weight DESC, rank_domain, rank_sub_domain, rank_addr, endpoint_id)`, expressed once in `profiles_query::order_terms` and served by the `endpoint_rank_key_v2` index. SQL stores the keys and never re-derives the order. Full write-up: [`reference/ordering-law.md`](../reference/ordering-law.md); ADR 0003, ADR 0010.
10. **The Profiles tab is a SQL page.** `PROFILES_PAGE_SIZE = 200` (`crates/leas/src/ops/profiles.rs`), hydrated in one statement; ordering, filtering and counting all run in SQL. ADR 0001.
11. **`profile_stats` writes are write-behind.** `WriteBehind<LinkSpec>` (`crates/leas-db/src/write_behind.rs`) owns every mutation, staged by column group (RESULT, PURGE, TRAFFIC) and flushed as one multi-row upsert window. ADR 0002, ADR 0014.
12. **Test-cell truth.** The Test column describes the endpoint's representative link, the argmin of the link key, not `active_link()`.
13. **Aggregate reads are raw SQL, one statement per scope.** The Details panel's bucket counts come from `profiles_aggregate` (`crates/leas-db/src/profiles_query.rs`) because toasty's typed builders have no `COUNT`/`SUM` projection. It is an inventoried raw-SQL site (cause C7, [`reference/database-manual-sql.md`](../reference/database-manual-sql.md) §3). The partition arms are `PlanScope::predicate` verbatim with `rank_proven` first, so a proven endpoint carrying bin 12 counts once and the members sum to the total. Design: [`../aegis/specs/2026-10-22-details-metrics-tasks-design.md`](../aegis/specs/2026-10-22-details-metrics-tasks-design.md) §5.

## Enrichment and networking

14. **Background enrichment never blocks the UI.** DNS, mmdb and whitelist work runs in spawned tasks reporting through `CoreEvent::EndpointInfoUpdated`, merged by field group. DNS lookups dedupe by host and fan the answer out to every waiter; failed lookups are TTL-gated by `scheduler.mark_dns_failure`.
15. **Country writes are queued.** One owner and one transaction per drain: `WriteBehind<CountrySpec>`, with `GEO_MAX_STAGED_AGE` (15 s) as the staleness deadline (`crates/leas/src/ops/enrich.rs`).
16. **Every network path has a hard deadline.** A hang is a bug.
17. **Feed ceilings are configuration.** `AppConfig.import.max_feed_bytes` and `max_feed_links`, where `0` means unbounded and the defaults equal the values that were previously hard-coded (`crates/leas-config/src/app_config.rs`).
18. **IPv6 answers are on by default; DNS stamp transport stays IPv4-only.** Lookups pass `allow_ipv6=true`; the DNSCrypt resolver-list parser (`parse_dnscrypt_lines` → `sdns_to_nsc`, `crates/leas-dns/src/lib.rs`) is deliberately `allow_ipv6=false`, because a stamp is the client's transport to the DNS server itself and unreachable v6 dials stall a pool lookup past the 8 s enrich deadline (`DNS_LOOKUP_TIMEOUT`). The host-features whitelist (`leas-host-features`) is IPv4-only for the same class of reason: the upstream data files list IPv4 entries only.
19. **The subscription decoder is chunking-invariant.** `StreamingDecoder` output depends only on the input bytes, never on how they are split across `feed()` calls (`crates/leas-config/src/subscription.rs`): encoding detection buffers a head until it is decisive, base64 is normalized to one alphabet, and line assembly runs on bytes so a line ends only at its `\n`. A single line over `MAX_LINE` is cut at the last scheme start; one over-long URL is dropped and counted, never silently truncated.

## Native core and TLS

20. **Composition order:** dial → security → transport upgrade → protocol → tunnel (`crates/leas-native/src/chain.rs`). TLS is outermost and ws/grpc framing runs inside it. `LinkContext` is the per-link policy surface every phase reads.
21. **The TLS fingerprint engine is ring-only** (`leas-tls`): TLS 1.3 with a TLS 1.2 fallback, declarative browser-hello profiles, WebPKI verification with only two trust modes, `insecure` and `pin_sha256`, never a blanket skip. REALITY reuses the same hello machinery. `leas-tls` and `leas-native` are both `#![forbid(unsafe_code)]`. ADR 0007; crypto sites: [`reference/crypto-dependencies.md`](../reference/crypto-dependencies.md).
22. **One HelloRetryRequest retry, plain TLS only** (`crates/leas-tls/src/handshake/mod.rs`). The HRR is recognized on its magic random before the extension scan; the retry obeys RFC 8446 §4.2.8.2 (selected group offered, no existing share, new key share, echoed cookie, transcript `message_hash(ClientHello1) || HelloRetryRequest || ClientHello2 …`). Under REALITY an HRR stays a typed error, because the sealed session id is bound to the first hello.
23. **Post-handshake policy lives in the record layer** (`TlsStream`, `crates/leas-tls/src/record/stream.rs`). Every handshake message in a record is walked; `KeyUpdate` rotates the read key and rekeys the write side at a per-key record cap (RFC 8446 §5.5); `NewSessionTicket` is dropped because resumption is not implemented. Direct mode, the Vision splice, bypasses the policy and says so on the type.
24. **Secrets are wiped.** Owned key buffers use `zeroize`, and the `zeroize` feature stays listed on every crypto dependency that touches keys.
25. **Per-host accounting is native-only and session-only.** The Sniffer pane's data comes from the in-process core: relayed TCP legs and UDP associations, plus pre-relay refusals (`TraceEvent::Failed`), keyed by the destination string as the client sent it (port stripped, no local DNS). Live bytes come from an open-leg registry sampled at 1 s (`CoreEvent::SnifferSample`); the table is capped at 1000 hosts (`HOST_TABLE_CAP`) and never persisted. Subprocess cores expose no per-host data and the pane says so. Contract: [`reference/native-core.md`](../reference/native-core.md); design: [`../aegis/specs/2026-11-03-sniffer-pane-design.md`](../aegis/specs/2026-11-03-sniffer-pane-design.md).
26. **A hello, a roster row, an HTTP/2 profile and a REALITY candidate are one identity.** Era gating in `gen_specs.py` decides which hybrid key share a claimed browser version may advertise (`PQ_ERA`); extension permutation is an identity property, not a spec field, and rides `handshake::connect_inner` as a bool decided from the resolved identity; `Resolved::http2_profile()` derives the SETTINGS/UA/`Accept` table from the same identity; REALITY eligibility is fingerprint-first (`RandomEligible` in `leas-tls/src/reality/mod.rs`). The per-claim evidence, including the JA4 variant default (`Ja4Variant::Foxio`) and the unassigned-codepoint screening, lives in [`reference/tls-fingerprint-roster.md`](../reference/tls-fingerprint-roster.md).
27. **Proxy control channels keep hyper defaults.** `transport/http/conn.rs` (v2rayhttp, xhttp) carries proxy traffic, not browser navigation, so it does not adopt the masquerade headers.
28. **Reference repositories are read-only.** `thirdparty/Xray-core` (primary Go core), `thirdparty/sing-box` (secondary Go backend), `thirdparty/v2rayN` (C# reference for protocol and URL formats, no longer a parity target), `thirdparty/shoes`, `thirdparty/leaf`, `thirdparty/shadowsocks-rust`, plus `v2rayNG`, `mihomo`, `quirktiva` and `v2ray-core-legacy`.
